Engineered for EC2201 Demonstration

Demonstrates fundamental digital logic synthesis from raw input encoding to combinational logic circuits and magnitude comparators.

Combinational Adder Tree

Implements a hardware popcount adder using Full Adders ($FA$) and Half Adders ($HA$) to sum 5 single-bit attributes into a 3-bit binary output $(S_2S_1S_0)_2$.

Sum = A + B + C + D + E
32-Minterm Truth Table

Evaluates all $2^5 = 32$ possible combinations from $m_0$ to $m_{31}$, mapping each state to canonical SOP forms, Hamming weights, and security categories.

2⁵ = 32 States (m0 - m31)
3-Bit Magnitude Comparator

Applies digital comparator logic equations to classify strength into 4 deterministic intervals: Weak (0-1), Medium (2-3), Strong (4), and Very Strong (5).

Decoder: W, M, S, V
