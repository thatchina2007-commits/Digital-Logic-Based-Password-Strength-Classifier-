EC2201 Mini-Project Viva Voce Examination Guide

Key technical questions and concise theoretical answers for faculty demonstration.
Q1: Why represent password attributes as Boolean variables instead of numerical lengths?

Answer: Mapping continuous or heterogeneous password features into a discrete 5-bit vector $\mathbf{X} = [A, B, C, D, E] \in \{0, 1\}^5$ enables deterministic combinational logic synthesis. It bounds the entire input domain to exactly $2^5 = 32$ states, allowing complete formal verification via truth tables and constant $O(1)$ hardware gate delays.

Q2: Explain the circuit architecture used to calculate the total strength score.

Answer: The circuit implements a hardware population count (popcount) adder tree. Stage 1 utilizes a Full Adder $\text{FA}_1$ to sum inputs $A, B, C$ and a Half Adder $\text{HA}_1$ for inputs $D, E$. Stage 2 adds the first-stage sums using $\text{HA}_2$ to establish the LSB $S_0$. Stage 3 accumulates all generated carries using $\text{FA}_2$ to yield bits $S_1$ and MSB $S_2$, forming the 3-bit binary representation $(S_2 S_1 S_0)_2 \in [0, 5]$.

Q3: How does the 3-bit magnitude comparator classify the score into 4 categories?

Answer: The comparator decodes $(S_2 S_1 S_0)_2$ via simplified Boolean equations:
• Weak (0-1): $W = S_2' \cdot S_1'$
• Medium (2-3): $M = S_2' \cdot S_1$
• Strong (4): $S = S_2 \cdot S_1' \cdot S_0'$
• Very Strong (5): $V = S_2 \cdot S_1' \cdot S_0 \equiv A \cdot B \cdot C \cdot D \cdot E$
Binary combinations $(110)_2$ (6) and $(111)_2$ (7) are treated as Don't Cares ($d$).

Q4: What is the significance of Minterm m31 versus Minterm m0?

Answer: $m_0$ corresponds to binary vector $00000$ (Hamming weight 0), representing an empty or non-compliant credential categorized as Weak. In contrast, $m_{31}$ corresponds to vector $11111$ (Hamming weight 5), which is the unique state satisfying all 5 criteria simultaneously, yielding the maximum resilience tier Very Strong.

Q5: How could this design be realized in physical hardware?

Answer: The combinational network can be synthesized directly into a Field Programmable Gate Array (FPGA) using Verilog/VHDL or etched onto an ASIC security coprocessor. At 45nm CMOS technology, this 5-bit popcount and comparator requires fewer than 50 equivalent NAND gates and evaluates in under 1 nanosecond.
