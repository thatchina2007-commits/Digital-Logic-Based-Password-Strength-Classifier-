EC2201 CURRICULUM MAPPING

About the Project

A bridge between classical hardware combinational logic design and modern cybersecurity entropy analysis.

Problem Statement

Why digital logic for passwords?

Conventional software password evaluation often relies on non-deterministic heuristics or heavy statistical libraries that are hard to verify formally or synthesize into hardware security modules (HSMs).

This project formalizes password complexity through binary discrete attributes ($A, B, C, D, E \in \{0, 1\}$). This allows deterministic classification via combinational Boolean networks, enabling hardware coprocessors to evaluate credentials in constant $O(1)$ gate-delay time with zero software overhead.

Project Objectives

EC2201 Course Learning Outcomes
  • Binary Encoding: Map arbitrary human credentials into 5 canonical Boolean logic flags ($A, B, C, D, E$).
  • Adder Tree Synthesis: Synthesize a 5-input population count (popcount) circuit using Full Adders ($FA$) and Half Adders ($HA$).
  • Comparator Classification: Design a 3-bit magnitude comparator decoder to classify sum outputs into 4 resilience tiers.
  • Truth Table Completeness: Formulate and verify all $2^5 = 32$ minterms in canonical SOP/POS formats.
  • Hardware-Software Co-Design: Deliver a functional, interactive software simulator suitable for viva examination.

Detailed Digital Logic Concepts

1. Boolean Variables ($A, B, C, D, E$)

Every password is mapped into a discrete 5-dimensional Boolean space $\mathbb{B}^5$. Each coordinate corresponds to an orthogonal complexity metric.

  • $A = 1 \iff \text{Length} \ge 8$
  • $B = 1 \iff \exists c \in [A-Z]$
  • $C = 1 \iff \exists c \in [a-z]$
  • $D = 1 \iff \exists c \in [0-9]$
  • $E = 1 \iff \exists c \notin [A-Za-z0-9\s]$
2. Full Adder & Half Adder Networks

Instead of software addition, the total score is accumulated using hardware adder primitives:

• HA: Sum = X ⊕ Y, Carry = X · Y
• FA: Sum = X ⊕ Y ⊕ Cin
  Cout = (X · Y) + Cin · (X ⊕ Y)

The outputs resolve to $S_2 S_1 S_0$ representing binary values from $000_2$ to $101_2$.

3. Truth Table & Minterms ($2^5 = 32$)

The entire state space consists of exactly $2^5 = 32$ minterms ($m_0$ to $m_{31}$). Each minterm represents a specific combination of criteria, categorized by its Hamming weight (the number of 1s in the vector).

For example, $m_{31} = A B C D E$ is the unique state where all 5 attributes are satisfied, producing the classification Very Strong.

4. 3-Bit Magnitude Comparator & Decoder

The 3-bit binary vector $(S_2 S_1 S_0)$ is decoded through logic gates into 4 mutually exclusive classification signals:

• Weak (W) = S₂' · S₁'
• Medium (M) = S₂' · S₁
• Strong (S) = S₂ · S₁' · S₀'
• Very Strong (V) = S₂ · S₁' · S₀
