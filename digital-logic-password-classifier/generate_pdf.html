Abstract

With the rapid proliferation of automated credential stuffing, rainbow table lookup, and high-speed brute-force attacks, robust and deterministic password strength classification has become a cornerstone of modern cybersecurity infrastructure. Conventional software checkers typically depend on heuristic thresholds or compute-intensive statistical libraries that lack mathematical verifiability and cannot be easily translated into hardware-level security primitives.

This project presents the Digital Logic Based Password Strength Classifier, an engineering prototype designed and implemented for the EC2201 & EC2202 Digital System Design and Microprocessor course. The system maps raw password credentials into a discrete 5-bit Boolean input vector X = [A, B, C, D, E] ∈ {0, 1}5, representing string length (≥ 8 characters), uppercase letters, lowercase letters, numerical digits, and special symbols.

The population count (popcount) is computed via an interconnected combinational adder network comprising Full Adders (FA) and Half Adders (HA) to generate an exact 3-bit binary sum (S2S1S0)2 representing the total Hamming weight (0 to 5). A 3-bit Magnitude Comparator and Decoder evaluates this sum into four distinct resilience categories: Weak (0–1), Medium (2–3), Strong (4), and Very Strong (5). The design is fully verified across all 25 = 32 canonical truth table minterms (m0 to m31), a 5-variable Karnaugh Map, and 15 automated test cases achieving 100% accuracy with constant O(1) gate delay.

1. Introduction

Password authentication remains the most ubiquitous security mechanism across digital communication systems, enterprise databases, and embedded computing devices. Despite advances in multi-factor authentication, textual credentials constitute the initial gatekeeper against unauthorized penetration. Analyzing password complexity through hardware-inspired digital logic bridges foundational electronics engineering with practical cyber-defense. The objective of this project is to develop a responsive, deterministic software prototype that evaluates password strength using Boolean logic, Full/Half Adder networks, 32-state Truth Tables, and Magnitude Comparators.

1.1 Real-World Problem / Use Case

Over 80% of security incidents originate from weak, default, or easily guessable passwords. Conventional software checkers rely on complex, non-standard heuristics that cannot be readily verified or fabricated into hardware security modules (HSMs) or FPGA-based coprocessors. Transforming credential validation into a combinational logic problem enables deterministic verification, zero statistical ambiguity, and sub-nanosecond hardware execution.

2. Problem Statement

To design, simulate, and deploy a digital logic-based password strength classification system that converts arbitrary textual passwords into a 5-bit Boolean vector (A: Length ≥ 8, B: Uppercase, C: Lowercase, D: Digit, E: Special Symbol), computes the total Hamming weight using a combinational Full/Half Adder tree, and classifies the resulting 3-bit sum (S2S1S0)2 ∈ [0, 5] into four discrete tiers (Weak, Medium, Strong, Very Strong) with complete mathematical and truth-table verification.

3. Implementation

3.2 Implementation Steps

  • Step 1 — Binary Extraction: Mapped passwords into Boolean inputs: A = (Len ≥ 8), B = ([A-Z]), C = ([a-z]), D = ([0-9]), E = (Special Symbols).
  • Step 2 — Adder Tree Synthesis: Synthesized a 3-stage adder tree:
    Stage 1: FA1(A, B, C) → S1a = A ⊕ B ⊕ C, C1a = AB + C(A ⊕ B)
             HA1(D, E) → S2a = D ⊕ E, C2a = D · E
    Stage 2: HA2(S1a, S2a) → S0 (LSB) = S1a ⊕ S2a, C3 = S1a · S2a
    Stage 3: FA2(C1a, C2a, C3) → S1 = C1a ⊕ C2a ⊕ C3, S2 (MSB) = Carry Out
  • Step 3 — 3-Bit Comparator Decoder: Decoded binary sum (S2S1S0)2 into 4 categories:
    Weak (0–1): W = S2' · S1' [Σ m(0, 1, 2, 4, 8, 16)]
    Medium (2–3): M = S2' · S1 [Σ m(3, 5, 6, 9, 10, 12, 17, ...)]
    Strong (4): S = S2 · S1' · S0' [Σ m(15, 23, 27, 29, 30)]
    Very Strong (5): V = S2 · S1' · S0 [Σ m(31) = A · B · C · D · E]
  • Step 4 — Web Interface & Analytics: Created 9 web pages including interactive circuit simulation, 32-row truth table, 5-variable K-Map, test suite, and PDF report generator.

3.3 System Design / Architecture

The system architecture follows a sequential digital hardware pipeline. Raw password inputs are encoded into 5 discrete Boolean lines, processed through a multi-stage population count adder network, and decoded via magnitude comparator equations:

+-----------------------------------------------------------------------------------+ | HARDWARE COMBINATIONAL ARCHITECTURE | +-----------------------------------------------------------------------------------+ | Raw Password Input | | | | | v | | [5-Bit Binary Feature Extractor] | | A (Len>=8) B (Upper) C (Lower) D (Digit) E (Special) | | | | | | | | | +-------------+------------+ +------------+ | | | | | | [FA1: A + B + C] [HA1: D + E] | | Sum1a C1a Sum2a C2a | | | | | | +----------------+----------------+ | | | | | [HA2: S1a + S2a] | | S0 (LSB) C3 | | | | | | | +------+------+ | | | | | | | | [FA2: C1a + C2a + C3] | | | S1 (Bit 1) S2 (MSB) | | | | | | | v v v | | 3-Bit Output Register (S2 S1 S0) | | | | | v | | [3-Bit Magnitude Comparator] | | +------------+---------------+------------+ | | | | | | | | WEAK MEDIUM STRONG VERY STRONG | | (Score<=1) (Score 2-3) (Score 4) (Score 5) | +-----------------------------------------------------------------------------------+

Component Explanations:

  • Feature Extractor: Evaluates criteria independently to produce orthogonal single-bit lines.
  • Adder Stage: Computes the Hamming weight (0 to 5) in hardware without software arithmetic.
  • Comparator Decoder: Executes simplified Boolean product-of-sums to activate mutually exclusive output LED indicators.

5. Conclusion and Future Scope

The Digital Logic Based Password Strength Classifier successfully demonstrates the practical application of combinational digital logic design (EC2201 & EC2202) to cybersecurity. By discretizing password attributes into 5 Boolean variables, calculating Hamming weight via Full/Half Adder networks, and classifying strength through 3-bit magnitude comparators, the system achieves deterministic, high-speed, and verifiable credential evaluation with zero heuristic ambiguity.

Future Scope:

  • HDL Synthesis: Synthesizing the combinational netlist into Verilog/VHDL for deployment on Xilinx Spartan-7 or Intel Cyclone V FPGA chips.
  • Hardware Microcontroller Interface: Interfacing with an ATmega328P / ARM Cortex-M microcontroller driving physical 7-segment displays and status LEDs for physical security access control.
  • Expanded State Space: Incorporating entropy variance and dictionary lookup into an 8-variable (28 = 256 minterm) extended logic array.
